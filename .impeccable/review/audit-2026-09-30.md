## Detailed findings

### P0 — Blocking

**[P0] Unresolved merge conflict deployed to production**
- Location: index.html (13–16, 54–57, 64–85, 92–121, 127–136, 179–183, 219–222, 235–246, 260–263), styles.css 332–440, script.js 1–7 / 15–91 / 100–415, hidden-rack.js (9 blocks). Commit 4b784ba, deployed 2c72209.
- Category: Implementation Integrity (cascades into all four others)
- Impact: The page shows literal `<<<<<<< HEAD` / `>>>>>>> 75e08d9…` text at the very top of the viewport and in 8 more spots; no interaction works; two layouts overlap; mobile scrolls horizontally (405 px on a 390 px screen); the form fails on submit; the "Pause" toggle can't pause the animated ident for motion-sensitive visitors.
- Standard: WCAG 2.3.3 (animation from interactions — pause control non-functional), 4.1.1/4.1.2 (broken scripts), 1.4.10 (reflow).
- Recommendation: Resolve every block to the HEAD side (that is the sampler-on-top-of-revision build you accepted in `hills-east-revision-acceptance.md`), confirm `node -e "new Function(fs.readFileSync('script.js','utf8'))"` on all three scripts, commit, push. The resolved copy at `/data/pat/.hermes/cache/scratch/he-resolved/` is already verified: 0 markers; stage knob, ratio bank, route selects → booking brief, ± nudges, motion toggle, ident poster swap, honest form note, triple-reset hidden rack (118 buttons, 16 pads) all confirmed working.
- Suggested command: none — this is a git fix, not a design command.

### P1 — Major

**[P1-1] Hero message and primary CTA below the fold on desktop**
- Location: index.html 42–90 (`.monitor`), styles.css 335–342 (`.monitor .crt { width:min(100%,680px) }`)
- Category: Implementation Integrity / Layout
- Impact: On 1440×900 the first viewport is the 680 px ident, its caption, "Play ident" and "Pause all motion". The h1 starts at y=973 and "Book a session" at y=1142; at 1280×720 it's worse. A Persuade surface hides its only promise and its only conversion until the visitor scrolls. Mobile is fine (h1 at y=584).
- Recommendation: Cap the monitor at ~`min(46vh, 520px)` on ≥900 px, or return the hero to a two-column unit with the ident left and h1 + lede + CTA right (the pre-revision layout did this — the acceptance note asked for "materially larger", not "alone"). Move "Pause all motion" into the 1U header next to nav so it stops being the third thing on the page.
- Suggested command: `/impeccable layout`

**[P1-2] Headline renders without a space: "Plug in.Sound like you."**
- Location: index.html 61 (`Plug in.<br>Sound like <em>you.</em>`), styles.css 340 (`.hero-face h1 br { display:none; }`)
- Category: Implementation Integrity
- Impact: The largest text on the site reads as a typo to every visitor and to screen readers ("Plug in.Sound").
- Recommendation: Replace `<br>` with a space (or wrap lines in `<span>` and control breaking with `text-wrap: balance`), and drop the `br{display:none}` hack.
- Suggested command: `/impeccable typeset`

**[P1-3] Functional text below the 11 px floor, systemically**
- Location: styles.css 39 (`.legend` .66rem = 10.56px), 77 (`.pushbtn` .62rem = 9.92px → nav, Book, Top, Use/Clear route), `.book-form label` and `.spec dt` 9.92px, 375 (`.dynamics-head > .legend` .55rem = 8.8px), 381 (LED numerals .6rem = 9.6px), 411–412 (`.crt-cap` .52rem = 8.3px, `.crt-cap .pushbtn` .5rem = 8px), 417 (`.optical-unit .legend` .48rem = **7.68px** on mobile), 428–429 (`.dynamics-controls .legend` .58rem = 9.3px).
- Category: Accessibility / Typography — 44 detector hits, 46 elements <10 px measured at 390 px.
- Impact: Form labels ("Your name", "Email", "Tell John about it"), nav labels, and the Gain / Peak reduction legends are the text people must read to act, and they're set at 8–10 px in a tracked uppercase face. On the silver plate at 7.7 px the control names are effectively illegible on a phone.
- Standard: WCAG 1.4.4 (resize text) / 1.4.12 — not a hard fail, but a legibility failure by any craft floor.
- Recommendation: Raise `.legend` to `.75rem` (12 px) and `.pushbtn`/form labels to `.72rem` minimum; on the faceplates never go below `.68rem`; give the LED numerals 11 px. Michroma is wide, so 12 px reads like 13–14 px in Archivo — the panel idiom survives.
- Suggested command: `/impeccable typeset`

**[P1-4] 1.65 MB animated ident as the eager hero asset**
- Location: index.html 46–49 (`<picture>` webp 1,654,570 B; gif fallback 6,787,253 B), styles.css 336
- Category: Performance
- Impact: 1,616 KB of the 1,871 KB total transfer is the ident, fetched before anything else can matter, then upscaled 480→680 px (soft). On 4G that's ~3–5 s before the first viewport is complete. The poster JPEG (80 KB) exists but is only used on pause/reduced-motion.
- Recommendation: Ship the poster as the `<img>` and swap in the animation after `load` (script already owns ident state — extend `syncIdent`), and re-encode the loop as `<video autoplay muted loop playsinline poster>` WebM/MP4 (source `hills-east-recording/Hills_East_Recording.mp4` exists) — expect 200–400 KB at 720². Keep the GIF out of the shipped tree entirely; no current browser needs it.
- Suggested command: `/impeccable optimize`

**[P1-5] Booking form is not connected (known / accepted)**
- Location: index.html 213–228, script.js 195
- Category: Implementation Integrity
- Impact: The only conversion path ends in "Not sent — this form isn't connected yet". On live it's worse: no JS, `novalidate`, POST to `#` fails. Disclosure is honest, which is right — but the site's job is a booking.
- Recommendation: Needs John's email → a Formspree/Netlify-Forms/Basin endpoint or a `mailto:` fallback with the route pre-filled in the body. Not a design fix; flagging so it doesn't get forgotten under the visual work.
- Suggested command: `/impeccable harden` (once an endpoint exists)

### P2 — Minor

**[P2-1] Skip link contrast 4.27:1** — `.skip` white on `--red` #e8322a. Location styles.css (`.skip`). Standard WCAG 1.4.3. Fix: darken the red for the skip chip only (`#c3271f` → 5.6:1) or use ink-on-amber. `/impeccable polish`

**[P2-2] Silver-plate disclaimer at 4.46:1 on the plate's darkest stop** — `.optical-unit .demo-note` #303535 sits at the bottom of a gradient that ends at #959c9c. Location styles.css 347, 370. Fix: `#202324` for the note (6.1:1) — same ink as the h2. `/impeccable polish`

**[P2-3] Header and Leveling Amplifier brand row overflow at 200 % text size** — scrollWidth 1349 on a 1265 px viewport with root 32 px; `.id-nav`, `.pushbtn--red`, `.optical-brand h2`, `.optical-face .knob-wrap` all break out. Standard WCAG 1.4.4 / 1.4.10. Fix: allow `.id-nav` to wrap (`flex-wrap`) and drop `white-space:nowrap`/fixed track widths on the plate at large rem. `/impeccable adapt`

**[P2-4] Footer utility range inputs 100×18** — `#lamp-level`, `#scan-speed` native `<input type=range>` with an 18 px track; thumb ≈ 14 px. Location index.html 240, styles.css 399–400. Fix: `height:44px` hit area with a styled track, or move these two into the hidden rack where they belong. `/impeccable adapt`

**[P2-5] `.reset` easter-egg button 70×35 and the brand link 155×17** — under 44 px. Reset is discoverability-by-design so 35 px is defensible; the brand link is a home anchor, so pad it to the 1U height. `/impeccable adapt`

**[P2-6] Infinite scanline animation paints a 650 px blended layer** — `.crt-glass` animates `background-position` under `mix-blend-mode:screen` forever (paused only when the CRT leaves the viewport). Location styles.css 116, 269. Fix: animate a `transform: translateY` on a pseudo-element instead of background-position, and honour the motion toggle (it does) — cheap win for phone battery. `/impeccable optimize`

**[P2-7] Faceplate palettes are 100 % hard-coded** — the revision block (styles.css 333–438) introduces ~40 literal hex colours (#f1f1eb, #c9cbc7, #959c9c, #202324, #94281f, #e2e1d7, #47251c, #ffcb55, #e85b3d…) and re-declares `--red` as literals. The materials are intentional; the lack of tokens means the two plates can't be tuned together. Fix: `--plate-silver-{hi,mid,lo,ink}`, `--plate-black-{…}`, `--led-amber`, `--led-off`. `/impeccable document` then `/impeccable extract`

### P3 — Polish

**[P3-1] No `<main>` landmark** — sections are children of `div.rack`; wrap units 2–7 in `<main>` so screen-reader users can jump past the header. `/impeccable harden`
**[P3-2] Caveat (75 KB) for seven tape labels, not preloaded** — subset to Latin basic (~10 KB) and preload; currently the handwriting FOUTs in after Michroma/Archivo. `/impeccable optimize`
**[P3-3] GSAP + ScrollTrigger (46 KB) for three scrub tweens** — could be `animation-timeline: view()` with a `@supports` fallback; keep if the hidden rack will use GSAP later. `/impeccable optimize`
**[P3-4] Three brand marks in one viewport** — Big Shoulders wordmark in the header, red italic "Hills East" script on the silver plate, drip-metal logotype in the ident. Pick the wordmark as canonical and let the ident be "art" not "logo". `/impeccable polish`
**[P3-5] No Open Graph / Twitter card tags** — the ident poster is a ready-made `og:image`. `/impeccable harden`

## Patterns & systemic issues

1. **Release process** — the P0 isn't a design bug; it's a missing pre-push check. Add a two-line guard: `git diff --check` (refuses conflict markers) and `node --check script.js hidden-rack.js pad-sampler.js` before `git push`, or wire `.impeccable/capture.cjs` / `revision-qa.cjs` (already in the repo) into a pre-push hook.
2. **One font-size token drives ~40 illegible labels** — `.legend` / `.pushbtn` at .62–.66rem, with per-unit overrides that go *down* (to .48rem). Fix the base, delete the overrides.
3. **Hard-coded material palettes** — 362 literal colour refs vs 144 token refs; concentrated in the revision block.
4. **Hero priorities inverted on desktop** — ident first, controls second, message third, CTA fourth.

## Positive findings — keep these

- **Reduced-motion is exemplary**: `prefers-reduced-motion` swaps the animated ident for the poster, relabels the toggle "Reduced motion on", disables it, stops the demo rAF loop, and pauses the scanline — state and hierarchy preserved, not a blanket kill. (Verified with emulated media.)
- **Accessible custom controls**: every knob is `role=slider` with min/max/now/valuetext, arrow + Home/End keys, and a ± button pair with aria-labels; ratio bank uses `aria-pressed`; route status uses `role=status`; the form has `aria-live` route summary; a `<noscript>` explains the fallback.
- **Patchbay has three equivalent input modes** (drag, tap-tap, native selects) and all three land in the booking brief without clobbering typed text. Pointer drags clear on `pointercancel`/`lostpointercapture`; jacks are 44 px with 58 px gaps at 390 px.
- **Honesty**: demo units say "no audio processing or equipment claim"; the form says it isn't connected; nothing pretends to be delivered.
- **Zero third-party requests**: fonts, GSAP, everything self-hosted; GitHub Pages compresses (gsap 72 KB → 28 KB on the wire); DOMContentLoaded 197 ms.
- **The rack metaphor is structural, not decorative** — U-heights, screws, rails, a power-conditioner footer with a three-press reset that mounts a working drum machine, synth and 16-pad sampler.
